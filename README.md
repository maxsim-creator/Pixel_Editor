# 🎨 Pixel Art Editor

Бесплатный браузерный редактор пиксель-арта. Работает прямо в браузере, без установки.

## ✨ Возможности

- ✏️ Карандаш, ластик, заливка, пипетка
- 📏 Линия, прямоугольник, круг (контур + заливка)
- 🖌️ Размер кисти 1–8 пикселей
- 🔲 Выделение: Shift+добавить, Alt+вычесть, драг внутри — двигать
- 📋 Буфер обмена на 40 записей
- ⚖️ Симметрия по X / Y
- 🔄 Повороты на 90°, отражения H/V
- 🌍 8 языков: RU, EN, UK, DE, ES, FR, JA, ZH
- ⌨️ Горячие клавиши (работают на любой раскладке)
- 💾 Импорт / экспорт PNG
- 🎯 Поддержка сетки, тёмной темы шахматки

## 🚀 Использование

Просто открой `index.html` в браузере или зайди на [GitHub Pages](([https://maxsim-creator.github.io/Pixel-Editor/](https://maxsim-creator.github.io/Pixel_Editor/)).

## 🌍 Языки

Автоопределение языка браузера + ручной выбор через селектор. Выбор сохраняется в localStorage.

## 🎮 Горячие клавиши

| Клавиша | Действие |
|---|---|
| `B` / `И` | Карандаш |
| `E` / `У` | Ластик |
| `G` / `П` | Заливка |
| `I` / `Ш` | Пипетка |
| `L` / `Д` | Линия |
| `R` / `К` | Прямоугольник |
| `C` / `С` | Круг |
| `M` / `Ь` | Перемещение |
| `S` / `Ы` | Выделение |
| `[` `]` | Размер кисти −/+ |
| `Ctrl+Z/Y` | Отмена / повтор |
| `Ctrl+C/V/X` | Копир / встав / вырез |
| `Ctrl+S` | Сохранить PNG |
